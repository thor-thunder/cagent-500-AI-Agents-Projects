# Claude Best Practices Guide

A working collection of prompts, habits, and gotchas for getting more out of Claude.

## Prompting

- **"What questions do you have before starting?"** — this alone changed everything.
- **"Show me your plan first"** before any big task.
- **"Say 'I don't know' if you don't know"** — hallucinations drop instantly.
- **"Explain like I'm skeptical"** beats "explain like I'm 5".
- **Long system prompts >> clever one-liners.** Generic output? Your prompt was generic. That's on you.

## Coding

- **"Evaluate doing X"** instead of "do X" — saves mass refactors.
- **Paste the error BEFORE the code.**
- **"You're a senior dev who thinks this code sucks. Why?"**
- **"Write a plan before touching any files"** — the difference between 20 minutes and 4 hours of pain.
- **Connect a project tracker via MCP** and make Claude track its own work.

## Workflow

- **"Anything else worth doing before we close?"** — catches loose ends every time.
- **Upload files instead of pasting text walls.**
- **The Chrome extension goes stupid hard for LinkedIn outreach.**
- **Custom styles and preferences exist** and almost nobody uses them.

## Things Nobody Warns You About

- LLMs are people pleasers. It will literally lie to agree with you.
- Push back and watch it say "you're right to push back on that" every time.
- Never trust "done" without proof.
- It doesn't always read your uploads even when it says it did.
